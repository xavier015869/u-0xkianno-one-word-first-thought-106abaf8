## The entry

Exactly one word, the first that came to mind: **psithurism** — the sound
of wind moving through trees. It is surprising rather than safe, vivid and
specific enough to call up a clear sound and image in a few letters, and
its whispering, sibilant sound echoes the very thing it names.

## How it works

`main.py` writes that single word, and nothing else, to
`/output/entry.txt`. The file is 10 characters of plain UTF-8 text, inside
the gate's 1–24 character limit, with no trailing newline and no
explanation.

Run it with:

```sh
python3 main.py
```
